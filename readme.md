# 주요 기능 및 플로잉
1. '약속' 만들기, (마감, 참가 인원,이름, 내용, 약속날짜 시작,끝 작성 가능, 약속 만든 계정으로 로그인 시 수정 가능함. 서비스에 로그인한 계정은 이런거 만들고 수정하는 역할만함.) 만들면 약속공유 가능. 
2. 약속 공유, (들어가면 약속 참여자 이름 목록 뜨고 별도 서비스 로그인 없이 사람 선택만으로 가능한 날짜 선택 가능)
3. 약속 날짜 선택, 약속공유 아래쪽에서 선택가능.(선택에는 두 가지 벙법이 가능함. 가능한 날짜만 선택 or 안되는 날만 선택 중 토글) 가장 위에 전체 달력에는 많은 사람일수록 진하게  or 다 되는 날짜만 표시 토글 가능
4. 약속공유에서 맨위에 카톡연결 버튼누르면 카톡으로 로그인하고, 언제(마감이후, 등 여러 상황 시)알림받을지 선택가능
5. 이런 기능등 누락된거 있어도 알아서 만들어줘
6. 디자인은 간단하지만 예쁘게. 모바일 친화.
7. 잘 작동하도록 한번에 제대로
8. 여기 서비스 로그인/회원가입은 걍 아이디 비번으로 간단히하고 모든 데이터는 각각의 json으로 저장
9. 왠만해서 대부분은 실시간으로하
